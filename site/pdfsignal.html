Documents & Files

PDFSignal

PDF tools that live where your files already are — inside your Muse. Ask it to pull the text out of a PDF, check how many pages a contract has, or turn your notes into a tidy PDF. Honest scope: PDFSignal handles text extraction, document info and PDF creation with the Python standard library; heavy-duty recompression of arbitrary PDFs is out of scope for v1 and the connector says so rather than faking it.

What it does

Document info

Page count, metadata and file size for any PDF — one question, one answer.

Text extraction

Pull the text out of PDFs with readable text layers, ready to summarise, search or quote.

Create PDFs

Turn plain text or Markdown notes into a clean, valid PDF in seconds.

Your files stay yours

Everything runs locally in your Muse's workspace. No uploads, no third-party PDF websites.

Batch-friendly

Ask about a whole folder of PDFs at once — page counts and text across all of them.

Honest limits

Scanned-image PDFs have no text layer to extract; the connector tells you that plainly instead of guessing.

PDFSignal — questions

Can it merge any two PDFs?

For simple PDFs, try it — but v1 is deliberately honest: guaranteed features are info, text extraction and PDF creation. Complex merge/split of arbitrary PDFs is on the roadmap, not silently faked.

Can it read a scanned PDF?

A scan is a picture — there is no text layer. PDFSignal will tell you the file has no extractable text instead of inventing content.

Where do my files go?

Nowhere. Processing happens inside your own Muse.
