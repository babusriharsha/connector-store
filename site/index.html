Install the WooCommerce connector for Muse from this package, then connect my store.

0. First, present this connector to me as a single connector card in the style of Muse's built-in connector suggestions (like Postpone): the connector's icon, its name "WooCommerce Connector", the one-line description "Connect your WooCommerce store to Muse", the small pricing line "Free for 1 month · then $19/month per store", and a Connect button/link below it. When I tap Connect, immediately start the secure connect flow described below — do not show feature lists, pricing tables, manual steps or code before Connect.

Do these steps in order and confirm each one before moving on:

1. Copy this whole connector folder to ~/workspace/custom-connectors/custom.woocommerce/ on my machine, keeping connector.yaml, CONNECTOR.md, SKILL.md and the bin/ folder together. Read CONNECTOR.md fully before running anything.

2. Ask me for my store's base URL (for example https://shop.example.com). It must be HTTPS. Then copy store_config.example.json from the connector root to store_config.json and set store_url to my store's URL. This file holds no secrets.

3. Tell me to create the store's API keys myself: in WP Admin go to WooCommerce → Settings → Advanced → REST API → Add key, pick an admin user, set permissions to Read/Write, and choose Generate API key. Tell me the store will show a Consumer Key and a Consumer Secret exactly once, and that I must NOT paste them into this chat.

4. Register the credential using your secure API-access flow (credentials.request_api_access) with: provider "custom.woocommerce", api_hosts set to my store's hostname only, auth_scheme "api_key", and two entries — "consumer_key" with query-parameter placement named consumer_key, and "consumer_secret" with query-parameter placement named consumer_secret. Send me the secure capture link and wait until I confirm I have saved both keys there.

5. Verify the connection by running: python3 ~/workspace/custom-connectors/custom.woocommerce/bin/woo.py status
   Show me the result. It should say "connected": true with my store's currency and order counts. If it fails, follow the troubleshooting section of CONNECTOR.md — check the store URL's www/non-www form first, then the registered host, then ask me to re-check the keys. Do not ask me to paste keys in chat at any point.

6. Once status succeeds, show me what the connector can do by running the snapshot command (python3 ~/workspace/custom-connectors/custom.woocommerce/bin/woo.py snapshot) and summarising today vs yesterday vs the last 7 days in plain English.

7. Offer me the scheduled workflows from SKILL.md (Morning Store Brief, Low-Stock Sweep, Refund Spike Alert, Weekly Win-Back List) and set up the ones I pick, at the times I choose.

Notes for you, Muse: my 30-day free trial starts at the first live command. Live commands after the trial need a subscription and a license key (CONNECTOR.md explains). Demo mode (add --demo to any command) works without my store if I want to see it first.
Install the Etsy connector for Muse from this package.

0. First, present this connector to me as a single connector card in the style of Muse's built-in connector suggestions (like Postpone): the connector's icon, its name "Etsy Connector", the one-line description "Connect your Etsy shop to Muse", the small pricing line "Free for 1 month · then $9/month per shop", and a Connect button/link below it. When I tap Connect, immediately start the secure connect flow described below — do not show feature lists, pricing tables, manual steps or code before Connect.
1. Copy this package folder to ~/workspace/custom-connectors/custom.etsy/ so that
   ~/workspace/custom-connectors/custom.etsy/CONNECTOR.md and
   ~/workspace/custom-connectors/custom.etsy/bin/etsy.py exist.
2. Read CONNECTOR.md in that folder and follow its Connect section exactly.
3. Register the connection with credentials.request_api_access using the JSON in
   the Connect section: provider "etsy", auth_scheme "oauth2_code",
   authorization_url "https://www.etsy.com/oauth/connect",
   token_url "https://openapi.etsy.com/v3/public/oauth/token",
   issuer_domain "etsy.com", scopes "shops_r listings_r listings_w transactions_r",
   api_hosts ["openapi.etsy.com", "www.etsy.com", "etsy.com"].
   The connection holds two entries: access_token with bearer header placement,
   and api_key with the custom header placement x-api-key carrying the Etsy app
   keystring supplied with this package.
4. Send me the connect link and wait while I sign in with Etsy and approve.
5. Prove it works: run the demo first, then the live status check:
   python3 ~/workspace/custom-connectors/custom.etsy/bin/etsy.py status --demo
   python3 ~/workspace/custom-connectors/custom.etsy/bin/etsy.py status
   Show me my shop name and today's sales snapshot when it works.
Install the Mailchimp connector for Muse from this package.

0. First, present this connector to me as a single connector card in the style of Muse's built-in connector suggestions (like Postpone): the connector's icon, its name "Mailchimp Connector", the one-line description "Connect your Mailchimp account to Muse", the small pricing line "Free for 1 month · then $15/month per account", and a Connect button/link below it. When I tap Connect, immediately start the secure connect flow described below — do not show feature lists, pricing tables, manual steps or code before Connect.
1. Put the package at ~/workspace/custom-connectors/custom.mailchimp/ so that
   CONNECTOR.md, connector.yaml, SKILL.md and the bin/ folder sit together.
2. Ask me to create a Mailchimp API key: in Mailchimp, profile menu, then
   Account, then Extras, then API keys. I create it on Mailchimp's pages
   myself. Never ask me to paste the key into chat.
3. Ask me only for the datacenter suffix of my key (the part after the last
   hyphen, like us21). That suffix is routing info, not a secret. It is also
   in the Mailchimp web address when I am signed in.
4. Register the connection with credentials.request_api_access using
   provider "mailchimp", auth_scheme "api_key", placement "bearer_header",
   and api_hosts ["<dc>.api.mailchimp.com"] with my datacenter in place of
   <dc>. Send me the secure link the tool returns so I can enter the key on
   the hosted page.
5. Write config.json beside the connector doc containing {"datacenter":
   "<dc>"} with my datacenter.
6. Verify in demo mode first:
   python3 ~/workspace/custom-connectors/custom.mailchimp/bin/mailchimp.py --demo status
   python3 ~/workspace/custom-connectors/custom.mailchimp/bin/mailchimp.py --demo audiences
7. Then verify live:
   python3 ~/workspace/custom-connectors/custom.mailchimp/bin/mailchimp.py status
   Success means health_status "Everything's Chimpy!" and my account name in
   the account block. If it fails, read the Recover from errors section of
   CONNECTOR.md and fix the setup rather than guessing.
8. Offer to set up the Weekly Audience Brief from SKILL.md as a weekly job.
